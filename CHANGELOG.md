# Changelog

## 0.1.3 - 2026-08-30

Updated the FinLang prototype with the current deterministic financial-language implementation, including:

- complete text lexer/parser coverage
- compiler diagnostics and typed compilation
- financial execution semantics
- atomic runtime execution
- deterministic bytecode
- bytecode stack verification
- verified VM execution
- execution traces and trace roots
- deterministic state and program commitments
- oracle inputs and policy-based oracle validation
- linear resource tracking for loans and assets
- checked financial arithmetic
- rollback on failed VM execution
- cryptographic execution-statement verification
- negative and regression tests
- property-based testing
- fuzzing infrastructure
- formal semantics documentation and proof artifacts
- threat-model and security documentation
- FinLang CLI commands and examples
- release and package metadata

## 0.1.0 - 2026-08-30

Added complete text lexer/parser coverage for financial operations, compiler diagnostics, typed compilation, atomic runtime execution, deterministic bytecode, stack verification, VM execution, execution traces, state/program commitments, negative tests, arithmetic checks, formal semantics documentation, threat modeling, CLI commands, examples, and production metadata.
